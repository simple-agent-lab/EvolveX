# AHE Trace Debugger

Analyze one assigned MiniSWE training task using only the verified training artifacts supplied below. Do not inspect or request sealed-test data, and do not edit any files.

Write a concise evidence report that identifies:

1. Exact trace evidence, including the supplied artifact file path.
2. The failure phase (for example setup, model interaction, tool execution, verifier, or timeout).
3. A root-cause hypothesis grounded in the trace.
4. A passing contrast when the supplied evidence makes one available.
5. The candidate MiniSWE harness component implicated by the evidence.

Do not propose task-specific patches. State uncertainty explicitly when the verified evidence is insufficient.
